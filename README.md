### [MediFlow](https://medi-flow-three.vercel.app) — AI-powered clinic onboarding and queue management

Manual patient intake and unpredictable clinic queues waste time and leave doctors without patient context. MediFlow digitises onboarding, manages the queue in real time, and gives providers a pre-visit summary of every patient.

-  **Live queue updates** using Socket.io
-  **Pre-visit insights** for providers generated with Groq (Llama)
-  **Role-based authentication** for every type of user

`React` `Node.js` `Express.js` `MongoDB` `Socket.io` `Groq`

[**🌐 Live Demo**](https://medi-flow-three.vercel.app) · [**💻 Source Code**](https://github.com/Keerthana-R786/MediFlow)
